# 话题质量与段内预览优化

2026-10-29，本轮沿用“解析具体讨论点 → 人工选择 → 切分”的范围，针对已有真实结果与审核交互做小步改进。原始结果、确认修订、成片及失败调用继续保留。

## 已确认的问题

1. v1 的跨窗续接直接替换标题和摘要。同一课程中，05:39～10:49 的片段原先包含文档类型、标签、属性和 DOM，最后约 49 秒的续接把整段标题改成了 DOM，丢失前半段覆盖。
2. 标题标签片段摘要增加了原段语音未说过的 SEO 等常识。结构校验无法证明摘要忠实。
3. 首窗原响应的首话题返回 10 个关键词，而上限为 8。原修复提示只有通用的格式要求，未指出具体超限项。
4. 页面只能定位到片段开始，播放不会在片段结束处自动暂停；时间输入只在失焦时同步，无效输入还会被“—”替换。

## 实现

### 具体话题与续接

`topic-chapters-v2.2` 要求按可独立回看的讨论点分段：同一领域中的不同问题、对象或独立演示可以另分，简短列举或同一论点的解释无需机械拆开。没有硬编码课程章节、时间边界或输出数量。

标题、摘要和关键词要求只依据对应语音，不以画面上下文或常识扩写结论。续接必须保持上一话题标题，程序也保留首个标题，避免最后一个窗口改窄整段标题。模型仍负责判断是否同一讨论点，以及合并摘要是否完整；这两项不是程序可证明的准确性保证。

### 有界定向修复

校验失败返回固定规则和程序测量的数字，例如：

```json
{"rule":"KEYWORD_LIMIT","topic_index":0,"actual_count":10,"max_count":8}
```

修复请求带有可信核心首末语句 ID 和完整核心 ID 列表。若原输出的所有区间与续接标记已独立通过顺序、连续性和完整覆盖校验，额外提供仅包含源语句首末 ID 和布尔值的 `validated_topic_ranges`，要求只修元信息；修复后还会检查范围和续接标记逐项一致，改变则明确失败。

原范围不合法时，不提供这组锚点；仍只允许一次正常修复。不会把无效模型标题、摘要、关键词或自由文本回显为修复指令，也不会自行裁剪关键词、补齐语句或伪造模型结果。原响应、校验反馈、账本及失败成本保留。

### 人工审核体验

- 每段新增“预览本段”，使用当前编辑后的有效起止时间，结束时暂停。它是浏览器回看辅助，暂停受媒体事件频率影响，正式导出仍使用冻结的毫秒区间和 FFmpeg。
- 手动跳转、定位、修改边界、拆分、移除、重新读取、切换任务或卸载会清理预览；异步 `play()` 使用代次隔离，迟到的旧请求不会清除同播放器的新预览。
- 时间输入按 `input` 保留原始字符串，立即参与校验和未保存状态。无效内容失焦后仍可见，禁止保存和预览；有效值失焦后格式化。
