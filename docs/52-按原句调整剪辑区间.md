# 按原句调整剪辑区间

2026-11-07。按需剪辑的保留区间支持通过原句文字和时间选择起句、止句，不要求用户记住转写 ID。选择先保存在弹窗草稿中，明确应用后才进入本页方案草稿；保存、确认和正式导出仍走原流程。本功能使用既有转写，不调用 ASR 或文本模型。

## 选择与应用

在目标的某个保留区间打开原句选择器，切换“起句”或“止句”后选择对应原文。范围从起句的开始时间到止句的结束时间，允许起止为同一句；这属于句级边界调整，不支持词级精切，也不推测句内单词时间。

原句按源顺序展示，每页最多二十条列表原句，可展开前后文。搜索同时匹配原文和显示时间，使用 NFKC、大小写归一化及空白分词 AND 的字面匹配，不把用户查询解释为正则或 HTML。“定位起句”“定位止句”清空搜索并回到对应原句所在页；分页保留末页内容，不截断较长转写。

- “取消”或关闭弹窗放弃本次选择，不改主方案草稿。弹窗内更换端点不会即时改写主方案。
- “应用区间”把合法边界写入本页草稿，实际变化时刷新该目标的来源证据。相同端点和毫秒值的 no-op 不额外制造 dirty。
- “应用并预览”先完成同样的本地应用，再按该段回看原视频；预览继续遵守[连续预览](./51-剪辑区间连续预览.md)的取消、隐藏和迟到事件约束。

应用不是服务端保存。用户核对后仍需保存方案、确认版本，再按原权限生成成片；选择器不会隐式发出保存、确认或导出请求。

## 边界和权限

`validateTranscriptRange` 根据完整来源表校验唯一原句 ID、整数毫秒、源时长及按序非重叠的原句时间。选定的两个 ID 必须存在，结束不能早于开始；成功返回全新的四字段 part，时间严格取原句边界。

已排除原句不能作为端点，选择跨过已排除的中间原句也会被拒绝，不会自动取消排除。新范围须与其他已完整合法的保留区间保持顺序且不重叠；另一段尚未完成或边界无效时，允许逐段修复。完整方案仍需通过原 `intentOutputValidation`，局部修改成功不代替整份方案校验。

FOUND 与 NEEDS_REVIEW 可调整合法区间，NOT_FOUND 或未知状态不可调整。应用不会把 NEEDS_REVIEW 改成 FOUND，不改变 enabled 或其他业务权限；待复核目标仍不可勾选导出。纯校验函数不修改原 output、排除项或语义证据。

## 上下文与迟到回调

打开时复制目标及来源原句作为本次弹窗草稿，并冻结请求、视频与转写身份、源时长、服务端/本地双 revision、目标区间和排除项签名。应用前重新核对上下文，并在当前来源上再次校验范围；“应用并预览”开始播放前还要复核双 revision、来源哈希与时长等身份。普通轮询产生的等值对象不应使选择失效，也不能把实际的新 revision 当成原选择的版本。

上下文失效时，旧选择只可查看，不能应用到新方案。隐藏时保留弹窗 scratch，返回后复核上下文；每次打开使用独立 token，旧弹窗的关闭或应用回调不能作用于新目标。取消或关闭后，只在入口仍存在且当前工作区有效时恢复焦点。

这些来源失效、隐藏保留 scratch 和 token 隔离约束经过源码审查及纯 helper 边界测试；本轮没有把它们报告为真实跨客户端 revision 变化或任务切换的 E2E 验收。
