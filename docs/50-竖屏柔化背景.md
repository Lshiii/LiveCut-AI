# 竖屏柔化背景

2026-11-07。既有课程成片转为 9:16 时，完整横屏画面居中、上下补黑。真实样例显示黑边占比很大；新增可选柔化背景版式，让同源画面填充背景，清晰前景仍完整保留。本轮改善成片呈现，不宣称 AI 重构画面或已验证付费需求。

## 使用行为与冻结协议

- 在“带字幕视频”的输出画幅增加 `PORTRAIT_BLUR_720`，展示“竖屏背景柔化 · 720×1280”。默认仍为 SOURCE；旧 SOURCE、LANDSCAPE_720、PORTRAIT_720 及其已有成片保持原行为。
- 新选项说明：完整保留前景画面，用原视频柔化背景填充竖屏，减少黑边。原有普通竖屏仍明确为补边；不以 CSS 样式示意冒充真实背景渲染。
- 创建请求仍精确四字段，使用已有独立未决回执、确认字幕、幂等与预算约束。新枚举进入现有 request/render/snapshot/stage_input hash，同 key 换版式继续返回冲突，新 key 产生独立成片。
- 输出恒定 720×1280；schema_version、caption-burn-v1、h264-aac-burn-v1 不变。该新枚举固定下述算法；不修改旧枚举语义、不加自由滤镜或可变强度输入、不迁移或重写旧记录。
- 两种字幕样式继续可选；ASS 文字、时间和排版与普通 720×1280 竖屏相同。新背景先合成，再进行真实字幕烧录；不重新提交 ASR 或模型分析。

## 媒体实现约束

从同一已验证 clean MP4 的视频流 split 两路：

1. 背景路把完整源帧缩放至固定 360×640，以 `gblur=sigma=20:steps=2` 柔化，放至 720×1280，再用 `eq=contrast=0.8:brightness=-0.04:saturation=0.8` 降低背景干扰。仅装饰背景允许比例拉伸，避免中心区域恰为黑板时仍得到近乎全黑的背景。
2. 前景路完整 contain 到 720×1280 范围，居中叠在背景上，不裁掉前景任何一侧。偶数像素舍入导致的比例近似沿用视频像素约束。
3. 在合成结果上执行原程序生成 ASS，设置方形像素，输出 H.264/yuv420p；原片有音轨才映射 AAC。

前景尺寸先由程序根据已验证输入算成有界偶数，最小 2 像素、不大于输出画布；背景直接缩放到上述固定尺寸。不能对极宽或极高素材先做 cover 放大，以免产生巨大的中间帧；不能产生零尺寸。graph 和参数均为程序常量，不拼用户滤镜。

新分支使用固定 `-filter_complex_threads 1`、编码线程 2；旧分支保留原 simple-vf 和参数。不得通过 trim、setpts、全局 shortest 或重切 parts 改变原成片时间。继续使用现有 FFMPEG 槽位、真实进度、guard、租约、取消、完整解码及原子发布。

## 兼容与发布顺序

当前 Worker 注册按阶段声明能力，没有按画幅版本分流。旧 Worker 会拒绝新枚举；旧前端也会拒绝包含未知枚举的历史快照。因此本机采用协调停机发布：确认执行器空闲且没有待恢复调用，停止旧 Worker，更新 Java，再启动兼容新旧四种画幅的 Worker，最后启用前端选项。新 Java 发布前，不在界面展示新选项；前端更新完成后才创建真实新任务。原有任务、原片、确认字幕、模型账本和生成记录保留。

本次不承诺混跑旧 Worker。后续多执行器部署若需要滚动发布，应增加实际可路由的渲染能力版本；仅添加展示用版本号不能解决领取兼容性。

真实课程在 18.140 秒的画面用于设计原型对比：中心裁切落到黑板，柔化后背景仍几乎全黑。因此最终改为完整源帧生成装饰背景。原型位于忽略目录 `data/runs/portrait-blur`，与下方通过任务执行器生成、下载及完整解码核验的正式成片分开记录。

## 验收要求

- Java：新枚举仅接受 720×1280；未知枚举拒绝；同 key 换版式冲突；新旧竖屏的 render/spec/snapshot/stage_input 身份隔离，旧记录可读。
- Python 真实 FFmpeg：横屏合成素材的四角标记全部留在清晰前景；背景来自源画面并有可测的柔化/暗化，而非仅判断“非黑”。覆盖有声、静音、字幕出现与消失、时长与全解码、极端 4096×2/2×4096/2×2、取消后无发布。旧 argv 和 ASS golden 保持，新版式与普通竖屏 ASS 字节一致。
- 前端：新选项、固定尺寸与说明正确；默认不变；新旧版式未知回执隔离且可刷新恢复，已冻结任务不能被后续表单配置改变；成功后显示真实 MP4 与实际版式。
- 本机真实课程与多区间两类成片：与原普通竖屏比较抽帧，人工查看前景、背景和字幕；核验下载大小/SHA、HEAD、Range、音轨、时长及全解码。原业务资源与模型账本保持，界面桌面及手机可用。
