# 当前执行需求：无商品清单自动切片

2026-10-23｜本文件优先于立项时含 SKU 清单的设计。

用户明确要求：不提供 SKU 或商品清单；开发方自行寻找公开可下载的视频，验证能否自动提取其中垃圾袋、面膜等商品对应的子视频。这些商品是需求示例，不要求每份测试视频都同时包含它们。

## 输入与输出

- 必需输入只有视频；可选输入是想找的商品名称筛选条件，例如“面膜”，不是预置 SKU 目录。
- ASR 和语义模型先从视频发现商品类别/可辨识款式，再生成产品实体及独立讲解区间。
- 自动实体 ID 仅在本次分析内有效，不代表外部真实 SKU。名称相近但明显不同款式不应强行合并；证据不够时请求审核。
- 同商品返场保留多个独立区间。用户选择产品后分别导出这些区间，暂不做跨时段混剪。
- 结果 Schema 升级到 2.0：以 products 和 product_id 替代输入目录与 SKU 引用；允许没有发现商品的合法空结果。
- 身份状态为 identified、ambiguous、unknown、not_applicable；unknown 需要审核原因 UNKNOWN_PRODUCT。

## 开发顺序

1. 无目录契约校验、数据集来源/划分管理、可运行 CLI。
2. 媒体探测、音频提取、准确切片，验证非关键帧裁切。
3. 下载真实连续商家回放，保存来源、原片偏移、哈希，媒体留在被忽略的 data。
4. 真实 ASR → 无目录商品发现/分段 → 契约校验 → 自动建议切片。保留原始预测，不先手改再宣称成功。
5. 核对面膜等片段起止与内容。网页商品跳转点/人工标签只用于独立评测，不能进入模型输入。
6. 核心能力验证后继续 Java 持久调度、审核版本、导出、视觉策略和可靠性工程。

## 评测口径调整

主指标仍为商品讲解区间 Precision/Recall/F1、Temporal IoU、边界误差、返场归并、审核时间和成本。身份指标改为人工标注类别/可辨识款式下的产品区间正确率，取消外部 SKU 金标准前置要求。类别分组正确不代表精确 SKU 识别。

无清单会增加未知身份、代词和同类商品歧义。保留不确定结果，不能要求用户补清单，也不能靠手写关键词边界替代自动理解。

## 当前真实测试素材

首轮使用康是美网购 eShop 的公开商家回放：https://livebuy.tv/replays/k3BqqM 。下载连续原片 36:40–46:40 作为 10 分钟开发样本；来源、原片偏移和哈希保存在本地 data/raw。包含面膜、保湿霜等介绍，不包含已验证的垃圾袋案例。
