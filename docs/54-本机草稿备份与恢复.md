# 本机草稿备份与恢复

2026-11-07。字幕校对与按需剪辑增加浏览器本机草稿备份。界面明确区分“本机已备份”和“已保存到服务端”，恢复须由用户明确选择，不自动提交业务操作。

## 备份内容

- 字幕：可编辑字幕字段、未完成或无效的时间原字符串、删除及撤销所需数据、基础 revision/content_hash、完整来源身份，以及保存结果待核对标记 needs_check。
- 按需剪辑：尚未提交的新要求、原始预算输入、方案可编辑字段、基础 revision/plan_hash、来源身份及 needs_check；不完整输入可以继续保留待修。
- 不复制完整原句正文快照，不恢复确认勾选、请求 pending、播放状态或业务权限；原句和不可变字段由当前已校验服务端快照补齐。

保存回执未知时，即使字段撤回原 baseline，仍保留草稿与待核对标记。PUT 在途时备份也标记需核对，刷新后不能据此直接重复保存或确认。

## 显式恢复与版本边界

历史备份先展示来源和兼容性，用户选择后再读取服务端核对。当前有编辑或操作在途时，不覆盖当前草稿。
涉及已有方案或字幕的恢复，必须匹配来源、基础 revision 与内容哈希；未知、重复、乱序标识、非法结构和不可变字段改动均被拒绝。
字幕保留空文字和无效时间草稿，恢复后仍受原校验限制；截断句的 requires_review 根据原 boundary_partial 与恢复后的 reviewed 重新计算。
按需剪辑恢复旧请求时，先 GET 对应请求并核对来源、版本与编辑上下文，成功后才切回该请求；不把旧草稿套到当前其他请求。
同源但服务端版本变化时只能查看、下载，不覆盖新版或自动换 base；字幕编辑正文已与服务端一致时可提示无需恢复，剪辑备份不凭最小字段认领新版。
恢复成功后仍是本页草稿，需用户修正、保存和确认。needs_check 恢复后仍需只读核对，不恢复为可信保存回执。
异步读取须通过当前文档、版本和草稿守卫；隐藏或失效上下文中的迟到结果不能覆盖新编辑。

## 本机记录与清理

每次编辑器挂载产生独立 writer UUID，每次写入使用新的不可变 entry UUID key。
新记录写入成功后，才清理该编辑器自己上一条当前记录；失败时保留旧记录。
刷新或重新挂载留下的历史备份、其他页面的备份不自动清理。历史记录可下载，明确确认后只移除所选记录，不按整个文档批量删除。
真正清净后只删除该编辑器自己的当前备份；保存 pending 或结果待核对不等于清净。卸载编辑器时保留未保存备份。

编辑后使用 250ms debounce；pagehide、beforeunload、隐藏和卸载时同步尝试补写，属于最佳努力。
只有 localStorage 写入成功才显示“已备份”；页面突然终止、浏览器清理站点数据、无痕模式或换设备时，不保证备份仍可用。
本功能不提供服务端草稿同步，不承诺替代服务端保存。

## 大小与失败处理

本机单份记录上限为 4 MiB，下载备份上限独立为 16 MiB；超出写入上限的当前草稿仍可在下载上限内导出。
存储被禁用、配额不足或写入失败时显示提示，当前编辑和此前成功记录保留；可下载当前草稿或手动清理不需要的历史记录。
字幕还检查数量、单条文字、时间原字符串及合计 UTF-8 大小，不能用本机恢复绕过原业务校验。
备份与恢复不自动发业务 PUT、创建请求、调用 ASR/模型、确认方案或生成导出。

## 验证范围

前端 275 项测试及类型检查、生产构建通过。纯测试覆盖独立 writer/entry、写入失败保留、精确删除、大小限制、来源与版本冲突、无效输入、删除撤销、文件归属与保存结果未知保护。历史记录显示编辑文字的短预览，保持 HTML 为字面文本，便于区分不同页面的草稿。

备份文件可通过“导入备份文件”在本页读取，按类型和当前视频、成片归属检查，先显示候选，再明确点击恢复；读取上限为 16 MiB，不上传文件、不自动写入浏览器存储或业务接口。当前有编辑时禁止覆盖。异步读取受文档身份和读取代次隔离，错误文件保留原有效候选；“移除本页导入”只移除内存候选，不删除磁盘文件或历史记录。

隔离浏览器复用真实组件，接口为明确标记的合成数据，验证了以下路径：

- 新独立文档默认打开最新已取消请求时，可恢复旧请求的标题、未完成第三段、新要求和空预算输入；来源或版本变化时只能下载。放弃方案保留另一页的新要求。
- 字幕文字、非法时间原串、单句复核标记、删除及撤销可恢复；全局确认保持未勾选，无效内容仍阻止保存和确认。
- 注入本机配额错误时不显示已备份；当前 JSON 文件可下载、导入并恢复。错误类型文件被拒，已有有效候选仍保留；恢复前新 GET 能拦住刚发生的版本变化。
- 两页分别备份 A/B，B 更新后旧移除确认消失，新备份保留；恢复副本再放弃不会接管或删除来源页记录。
- 顶层编辑页原生刷新后可找回草稿；输入返回后约 26ms 发起刷新也找到了对应备份，但不保证所有崩溃前尚未完成的写入都能恢复。原离开警告继续保留，部分刷新会被该警告阻止。
- 为验证待核对标记，分别明确点击一次合成方案保存、一次合成字幕保存，均被隔离接口拒绝；撤回原值后重建文档，恢复仍进入核对流程。没有真实业务写、确认、导出或模型调用；合成字幕初始化 POST 单独计数，不伪称全部 POST 为零。
- 320×800 下字幕对话框 304×784、宽度无溢出，底栏底部 791px；剪辑面板宽度 300px、无溢出，底栏底部 789px。移除剪辑区的重复滚动层后，下载、恢复、移除按钮的实际点击通过；备份工具栏保持可见。

文件下载和导入使用独立顶层编辑页验收；iframe 内的下载观察曾超时，未将其当作成功。合成历史记录先由产品下载归档，再逐项明确移除；测试标签与隔离服务已关闭，未遗留本轮浏览器测试草稿。

真实旧视频也经过新页面恢复和放弃回归，临时标题已恢复，23 项原业务资源的 canonical JSON 哈希与基线一致。本轮没有重新注入真实数据库提交故障、耗尽真实存储或查询供应商计费。原句选择器内尚未应用的临时选择、话题审核和对话输入不在本次备份范围。

以上是编辑草稿完整性与恢复边界的实现，不代表 Agent/RAG 效果提升、剪辑效率测量或付费需求已获验证。
