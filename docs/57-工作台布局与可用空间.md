# 工作台布局与可用空间

用户反馈工作台排版影响使用。本轮优先修正阅读、操作与滚动问题，保留原有解析和剪辑流程。

## 已调整

- 主导航增加图标和明确选中态，任务详情与创作入口分开摆放；手机保留完整文字入口。
- 视频对话、话题审核和按需剪辑统一预览/编辑的分区思路。正文、时间与辅助文字区分层级，话题标题 15px，正文 14px，主要话题操作至少 36px 高。
- 话题增加原视频回看、话题列表分区。移除父工作区在短窗口下强制 480px 最小高度的规则；窄屏或高度不超过 600px 时，正文使用一个滚动区域，原句与列表解除内部滚动，保存栏保留。
- 不超过 520px 高的任务侧栏整体滚动，避免列表被顶部工具区挤没。抽屉仍支持 Escape、焦点限制和关闭后焦点返回。
- 字幕窗口优先显示编辑正文。手机首次打开时收起预览；回看本句展开视频，收起预览立即暂停。备份、已确认版本下载和辅助版本操作折叠，保存与确认按钮常驻。修正旧全局 selected 样式造成字幕输入意外加粗。
- 话题成片的预览移至列表前方；点击后定位并聚焦预览，关闭后返回触发按钮。视频不自动播放，定位前再次校验当前工作区、任务、批次和片段。

## 保留的行为

本轮不修改业务接口、原始转写、自动预测、剪辑方案、导出文件或确认权限。标签切换继续使用现有 v-show 和 active 守卫，原有草稿、并发版本校验和字幕保存结果核对保持有效。展开、折叠与回看不发起模型请求。

## 验证记录

- 从暂存区单独导出快照后验证：296 项前端测试全部通过，vue-tsc 与 Vite 生产构建通过。未将并行开发中的 AI 字幕功能混入本次提交。
- 实际浏览器覆盖 1280×720、1366×600、320×812，以及 900×400 的低高度任务抽屉。四个主工作区在手机宽度下没有页面横向溢出；短窗口保存栏保持在可见区域内，任务抽屉可滚动到末尾并支持 Escape 返回触发按钮。
- 话题标题临时修改在切换标签、调整窗口大小后保留；测试结束恢复原文字，保存按钮重新禁用，没有向服务端保存修订。
- 实际字幕成片验证手机首次打开收起预览，回看本句展开并定位视频，收起后播放器暂停；未保存或确认字幕。
- 用已有两段 CS50 成片验证预览：定位后整块预览位于可见滚动区域内，焦点进入预览；关闭返回相应触发按钮，视频不自动播放。
