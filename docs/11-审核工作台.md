# Vue 审核工作台

当前本机工作台支持上传 MP4、创建任务、查看阶段状态、取消和重试、原视频播放、商品时间轴、ASR 证据、商品名与归属修改、边界编辑、拆分、移除、手动补漏，以及审核修订保存和确认。正式审核版本导出尚待 T6 接入。

## 启动和使用

需要 Node、Java/MySQL、Python/uv、FFmpeg，配置步骤见 README 和 07～09 文档。开发环境使用 Node 24.14.1。

```powershell
# 终端一，仓库根目录
./scripts/java.ps1 -Task Run
# 终端二，仓库根目录；模型凭证通过进程环境提供
./scripts/worker.ps1
# 终端三，frontend 目录
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。开发服务器仅绑定本机，转发 `/api` 到 Java 的 8080 端口。页面不接收、保存或显示模型与 Worker 密钥。依赖与锁文件随源码提交；`npm run build` 同时执行 TypeScript/Vue 类型检查和生产构建。

1. 上传非空 MP4（最多 1 GiB），或选择已登记视频。
2. 选择本地 OCR 或仅 ASR，设置本次文本请求次数上限，创建分析。该数字不是人民币费用；ASR 默认最多提交一次。
3. 查看四阶段进度。创建使用持久幂等键，关闭/刷新页面后按 URL 中 job ID 恢复选中任务。任务列表显示最近最多 100 条，统计基于已加载集合。
4. REVIEW_READY 后点击商品时间轴或“定位”，播放器跳转到原视频相应时间；语音证据显示所选区间内的 ASR。
5. 修改商品名、毫秒边界和归属；新增片段先默认禁用。按当前播放位置或区间中点拆分，首尾相接允许，启用片段不能重叠。
6. 保存新修订，再确认精确版本。未归属商品的启用片段不能确认。后续编辑产生新草稿，历史确认不被改写。

审核编辑不会被后台状态轮询覆盖。切换任务会检查未保存修改；关闭页面会触发浏览器的未保存提示。版本冲突时保留当前编辑并提示重新读取，不自动覆盖另一页。模型原始结果、人工修订、已确认版本的区别见 [审核 API](./10-review-api.md)。

## 本机验证

2026-10-24：TypeScript/Vue 类型检查与 Vite 生产构建通过。真实 MySQL 的审核 HTTP 集成测试 11 项通过，统一 Java Verify 77 项通过且无跳过。新增 GitHub 前端构建检查；CI 结果以实际运行状态为准。

浏览器连接真实 Java 服务和 600 秒真实视频，验证了页面创建任务、刷新恢复、取消、模型任务与失败状态区分；播放器取得 duration=600、readyState=4、无媒体错误。点击面霜时间轴后原视频跳到 190358ms，并显示相应 39 条 ASR 证据。938px 主页面无横向溢出；另用实际 320px iframe 视口检查了窄屏布局。没有将裁剪截图当作移动端重排。

两页面都从 r0 打开，第一页保存得到 r1，第二页的旧 base_revision 保存被拒绝，界面保留其本地修改并显示冲突。随后使用 r2 验证确认流程，勾选面膜与面霜两段。**这些修订由开发代理执行浏览器验收，不代表用户亲自逐段审核，也不作为模型质量标签。** r0 原始预测和来源哈希保持不变；后续真实使用可继续另存新修订。
