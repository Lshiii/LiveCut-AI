# 视频链接导入

通过网页粘贴 YouTube / Bilibili / 抖音的公开单条视频链接，由运行导入 Worker 的机器下载媒体。完成后选择“使用此视频”，再通过原来的分析入口设置预算并创建分析。导入本身不调用 ASR 或模型。

## 范围

- YouTube `youtube.com/watch?v=...`、`youtu.be/...`，Bilibili `bilibili.com/video/BV...` 或 `av...`。分享参数经过校验后归一为视频来源；播放列表、直播和其他站点明确拒绝。Bilibili 仅首 P，`p>1` 拒绝，避免悄悄下载错误分 P。
- 抖音 `douyin.com/video/<15～22位数字>`（也接受 `www` / `m` 子域）与 `v.douyin.com/<短码>/`。请只粘贴完整 HTTPS 链接，不接收整段分享文案、账号页、直播、图文或合集。普通分享参数归一化；含另一个视频身份或列表参数时拒绝，不悄悄换视频。
- 首版不读取浏览器 Cookies，不提供登录或付费内容的凭证入口。站点反爬、登录要求、地区限制或格式不可用时明确失败。
- 下载器当前只支持可直接取得的 HTTPS 音视频流，不支持 HLS/分片清单；不启用 JavaScript 挑战执行器。YouTube 链接能通过来源校验不代表该视频一定能下载，要求 JS 挑战、登录或其他不支持格式时会失败。首版真实成功样例见下文。
- 保留本地 MP4 上传。两种入口均最终注册 `video_asset`，分析、原句引用与成片使用注册后的文件及其哈希。
- 下载暂存与最终文件都有大小限制；最终文件遵守当前存储上限（最高 1 GiB）。导入 Worker 每次只执行一个导入。

## 启动与操作

先启动原有 Java API 和前端。在仓库根目录另开终端运行：

```powershell
.\scripts\source-import.ps1
```

该脚本从 `.env.java` 读取 Worker 凭证、共享存储及 FFmpeg 配置，通过锁文件安装 `source-import` 可选依赖并运行独立导入 Worker。需要 FFmpeg / ffprobe；Java 与导入 Worker 必须使用同一共享存储目录。Java 地址默认 `http://127.0.0.1:8080`，可通过 `-JavaUrl` 覆盖，配置文件可通过 `-EnvFile` 指定。

网页中打开“链接导入”，粘贴支持的链接并提交。状态依次显示排队、下载、格式处理、验证和完成。完成后显式使用视频，继续原有分析流程；需要分析时还须运行原计算 Worker `scripts/worker.ps1`。

取消会撤销本次执行资格。失败后可以显式重试，最多三次实际领取；取消的任务不会被重试复活。刷新页面后展开链接面板，通过服务端最近 20 条列表恢复任务；创建回执未知时保留原幂等键和原链接，先核对原提交。只有精确查询确认不存在，才能原样重发；放弃本地未提交记录前也会再次核对。

## 执行与来源

导入发生在 `video_id` 产生之前，因此使用独立 `source_import` 与领取回执，不向已有分析 `job_stage` 插入无来源的 DOWNLOAD 阶段。导入 Worker 使用独立 HTTP 轮询领取；它不消费分析阶段 Kafka 消息。

```text
链接 → Java 持久导入任务 → Python yt-dlp 下载
    → FFmpeg 规范化与 ffprobe 复检
    → Java 校验当前执行、固定路径、大小、MP4 头和 SHA256
    → 原子发布 videos/{video_id}.mp4 并注册 video_asset
    → 用户通过原有入口创建分析
```

任务状态为 `QUEUED → RUNNING → COMPLETED / FAILED / CANCELLED`。领取生成独立 attempt、run_token、90 秒租约及一小时硬截止；心跳不能突破硬截止。过期执行转 FAILED，由用户决定是否在原次数上限内重试。完成提交绑定同一执行与同一哈希，可核对重复回执；过期凭证不能发布结果。

Worker 只写本次固定目录 `imports/{id}/attempts/{attempt}/{run_token}/source.mp4`。Java 内部完成接口不接收任意本地文件路径。来源文件由 Java 注册，Python 不修改业务数据库。

下载文件不只按扩展名判断：需真实 MP4、H.264 视频和 AAC 音轨，且媒体时间起点符合现有处理要求。转码按共同起点归零，视频晚开始时补黑帧，音频晚开始时补静音，保留两轨相对时间；未知或超限时序明确拒绝。规范化后的文件是本项目统一时间源，并复核时长避免体积限制产生的截短文件被发布。视频页面标题或原站章节不作为模型定位标签。

下载在隔离子进程内执行，限制出站到公网地址，重定向和后续媒体请求也须经过地址检查；不接受任意 yt-dlp 参数、外部下载器或用户命令。进度只显示公开字段，错误采用固定代码，前端不接收 Worker 凭证、执行 token、临时签名下载地址或存储路径。

抖音短链由隔离下载进程解析，最多 5 次跳转，仅接受官方短链、`www.iesdouyin.com/share/video/...` 和抖音单视频页；一旦取得视频 ID，后续不得换成另一个视频。Java 只保存原规范链接，不自行联网展开。使用 yt-dlp 官方 `DouyinIE`；遇到访客会话要求时，仅在本次任务内存中接收匿名首页的 Set-Cookie，并至多重试一次。公开分享页只有实际提供同 ID 的 JSON 才能解析，不执行网页验证挑战或生成虚假元数据。

DNS 返回混合地址时只使用可核验的公网地址，连接时再次检查实际数值 IP；若全部为内网或代理 fake-IP（例如 `198.18.0.0/15`），明确失败为 `SOURCE_IMPORT_NETWORK_DENIED`。当前不支持经 fake-IP 映射下载；需要运行机器提供真实公网 DNS 解析，不能通过关闭校验解决。

失败或取消后仅清理本次执行的固定临时媒体文件；已生成的 `source.mp4` 与未知完成回执保留，供 Java 核对原请求。当前未实现历史导入成片的自动垃圾回收，长期使用应留意共享存储空间。

## API

公开响应遵循 `contracts/source-import.schema.json`。

| 接口 | 含义 |
|---|---|
| `POST /api/source-imports` | `{url}`，携带 `Idempotency-Key` 创建或核对原任务 |
| `GET /api/source-imports?limit=20` | 最近的导入摘要 |
| `GET /api/source-imports/{id}` | 单个导入状态 |
| `GET /api/source-imports/by-key/{key}` | 核对精确原创建请求 |
| `DELETE /api/source-imports/{id}` | 取消 |
| `POST /api/source-imports/{id}/retry` | `{expected_attempt}`，对所见失败尝试显式重试；迟到旧请求不能重试后续的新失败 |
| `POST /internal/source-imports/claim` | 带原领取键领取，内部 Worker 鉴权 |
| `POST /internal/source-imports/{id}/heartbeat` | 续租与进度 |
| `POST /internal/source-imports/{id}/complete` | 固定产物哈希、大小与执行身份验收 |
| `POST /internal/source-imports/{id}/fail` | 当前执行失败回报 |

GET 状态接口会顺带将过期 RUNNING 任务恢复为 FAILED；它们不发起下载、ASR 或模型请求。
