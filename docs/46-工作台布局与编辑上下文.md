# 工作台布局与编辑上下文

2026-11-07：针对任务列表、对话、话题表单及剪辑全堆在长页面上的使用问题，调整为任务侧栏与独立工作区。此次只改前端布局及播放器可见状态，不修改接口、模型流程和已有业务记录。

## 页面组织

- 左侧为视频/任务搜索、状态筛选、上传及新建分析；列表在固定侧栏内部滚动，不再随任务数量撑长页面。
- 右侧固定显示当前视频和状态；通过“视频对话 / 话题切分 / 按需剪辑 / 任务设置”进入相应工作区。
- 对话消息与会话列表独立滚动，输入区保留在底部可见位置。首次打开会话及本人发送时定位最新；用户正在阅读历史时，刷新不强制抢滚动位置。
- 话题列表默认紧凑展示，每次展开一段编辑，其他段输入仍保留在组件中。视频、转写与保存操作的字号和对比度重新调整。
- 任务设置保留来源、执行阶段、预算、失败诊断、取消、重试、转写复用和原视频；新建分析仍使用原幂等及预算流程。
- 窄屏使用可展开/关闭的任务抽屉；主内容占满宽度，标签支持键盘左右键及 Home/End 导航。

## 编辑与播放边界

标签切换使用稳定面板的 v-show，审核、剪辑和对话组件仍按原 job 身份挂载，不因标签卸载。因此隐藏的未保存输入、时间草稿、选中项和提交回执保持原状，并继续参与跨任务/视频切换、上传及重新分析的全局保护。

只在任务 ID 真正变化时选择默认工作区：已完成 topics 为视频对话，历史 commerce 为片段审核，其他状态为任务设置。同任务的 SSE、轮询或执行完成不会擅自切换用户当前标签。

组件增加可选 active 状态，旧调用者默认仍可用。隐藏时暂停所有原片/成片播放器，取消待执行的预览意图并拦截迟到播放；只停止媒体，不取消后台任务或清空草稿。Topic/Review 将可见状态传至嵌套 ExportPanel。Agent 剪辑预填先通过目标原有 guard，成功后才跳至剪辑区并在下一轮 DOM 更新后聚焦；拒绝时保持原视图和内容。

## 本机验证

真实工作区包含 29 个任务、7 个话题及 3 轮已有对话。在 1280×720 视口，调整前 document 高 13372 px、任务列表高 2726 px、对话输入区距顶约 7197 px；调整后文档为 1280×720，任务列表内部滚动，对话输入区位于屏内。在 320×800 窄屏，文档宽高为 320×800，没有整页水平溢出，输入和发送按钮可见；任务抽屉宽 288 px，可打开和关闭。此为该页面的布局观察，不是处理速度或业务效率指标。

真实浏览器检查包括：

- 同一视频中，对话输入和话题标题分别修改后切换标签，内容均保留；隐藏话题草稿仍阻止切到其他任务。
- 剪辑要求切换出去再返回保持，测试输入均恢复原值，没有保存/确认或提交请求。
- 实际话题预览已播放，切到对话后对应视频暂停，返回时不自动恢复。
- 键盘切换、任务设置和转写复用入口可见；旧 commerce 任务仍能打开原商品审核及导出，再切回 topics 默认对话。
- 当前分析、审核、已有剪辑及包含用户第三轮提问的会话共 4 个公共资源，与修改前基线完全相同，本轮没有新增模型或 ASR 调用。

前端全量 122 项通过，TypeScript 和生产构建通过，diff 检查通过。浏览器记录和截图位于忽略目录 data/runs/workbench-layout，不提交真实数据或截图到公开 Git。公开 CI 状态以本次提交对应检查为准。

## 话题审核工作区继续调整

复核发现，独立话题页仍将大播放器、说明、列表和导出纵向堆叠。在 1280×720 视口，审核卡片约 1211 px 高，列表从约 y=585 开始，保存栏在约 y=1032；仅把主页面分成标签还不足以解决审核体验。

话题面板进一步拆为“选择与编辑”和“成片导出”两个稳定子视图。桌面审核区左侧放视频、时间轴和对应原句，右侧放话题与编辑表单；原句和列表独立滚动，保存及确认栏在底部占固定空间。说明压缩为短提示。下载视图保留既有确认版本、JSON 留档和正式导出能力。

子视图切换不重新读取审核、不清空标题、关键词、选择和未完成时间输入；ExportPanel 保持相同任务实例，收到子视图可见状态后暂停隐藏成片。源视频在离开审核、外层标签隐藏及异步播放返回时均检查当前可见状态。确认成功才进入下载，不自动创建导出任务。

窄屏使用单列滚动，原句区域可折叠；审核操作栏保留在底部。此次不修改后端、模型调用、分析或已有确认/导出记录。单元检查不能证明排版正确，需结合真实页面的草稿、播放、历史导出和窄屏验收；本轮证据保存于忽略目录 data/runs/topic-layout。

本机复核结果：1280×720 时审核面板约 559 px 高，保存栏位于 y=636～703，话题列表有约 373 px 独立滚动空间；原句正文可见约 129 px、完整内容约 849 px，确认其内部可以滚动。1024×720 没有整页横向溢出，保存栏底部约 y=701。320×800 首次进入时原句默认折叠，展开正文最多 240 px 并可滚动，保存栏底部约 y=792，任务抽屉宽 288 px。

真实页面还验证了：标题和未完成的 `05:` 时间输入在子视图及外层标签间保留；草稿藏在下载视图时仍阻止跨任务误切；恢复原输入后可正常换任务。原视频与已有 MP4 成片均实际播放，再切子视图后暂停，返回不自动播放。历史课程确认版本及两条成片仍可查看，确认 JSON 下载成功，子视图支持左右键及 Home/End；页面无控制台错误。测试输入均已还原，没有保存新修订、确认或创建新导出，确认成功后的跳转仅作代码审查。

前端 122 项测试、类型检查和生产构建通过；当前分析、审核、剪辑、会话及历史课程审核/导出共 6 个公共资源与修改前完全相同，无新增模型请求。以上数字仅为指定视口下的布局观察，不代表处理速度、内容准确率或用户效率提升。
