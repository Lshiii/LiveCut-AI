## 页面组织

- 左侧为视频/任务搜索、状态筛选、上传及新建分析；列表在固定侧栏内部滚动，不再随任务数量撑长页面。

- 对话消息与会话列表独立滚动，输入区保留在底部可见位置。首次打开会话及本人发送时定位最新；用户正在阅读历史时，刷新不强制抢滚动位置。

## 编辑与播放边界

标签切换使用稳定面板的 v-show，审核、剪辑和对话组件仍按原 job 身份挂载，不因标签卸载。因此隐藏的未保存输入、时间草稿、选中项和提交回执保持原状，并继续参与跨任务/视频切换、上传及重新分析的全局保护。

只在任务 ID 真正变化时选择默认工作区：已完成 topics 为视频对话，历史 commerce 为片段审核，其他状态为任务设置。同任务的 SSE、轮询或执行完成不会擅自切换用户当前标签。

组件增加可选 active 状态，旧调用者默认仍可用。隐藏时暂停所有原片/成片播放器，取消待执行的预览意图并拦截迟到播放；只停止媒体，不取消后台任务或清空草稿。Topic/Review 将可见状态传至嵌套 ExportPanel。Agent 剪辑预填先通过目标原有 guard，成功后才跳至剪辑区并在下一轮 DOM 更新后聚焦；拒绝时保持原视图和内容。

## 阅读模式与区域层级修正

用户继续反馈工作台排版影响使用。本轮收紧顶部工具栏，保留文件名、分析轮次、任务列表和上传主按钮；四个稳定工作区改为明确的下划线导航，手机等宽排列。主区统一留白与卡片边界，避免顶部说明与正文争夺注意力。

视频对话在宽窗口支持“专注对话 / 并排回看”：前者只显示居中阅读区，后者显示原视频和回答。模式切换保留输入和滚动上下文，隐藏视频即暂停并撤销过期播放意图。在专注模式主动点击回答原句，会恢复并排回看并沿用原定位守卫，不增加模型请求。中等及手机窗口的视频参考默认折叠，可手动展开。

## 按需剪辑的要求、核对与交付流程

继续复核发现，按需剪辑仍把空白输入框、请求历史、视频、候选表单和成片纵向堆放。已有候选打开后还需要滚过输入区，成片则在所有候选之后。本轮将同一组件拆为三个稳定视图：“剪辑要求 / 核对方案 / 成片与字幕”，历史请求按需打开。首次读取及明确选择历史请求时，有导出批次优先展示成片，否则展示当前执行或方案；没有请求时展示输入。用户手动选页和 AI 预填优先于初次读取的默认入口，轮询不改当前页面。

桌面核对区为视频、执行信息与候选双栏，各自滚动；操作栏保留在卡片底部。小容器默认折叠视频与本次原要求，优先显示候选；执行进度、失败原因、取消和继续查找仍在折叠区域之外。定位原句会先展开视频，下一轮 DOM 更新后重新核验请求、选择版本、导航版本和可见状态，再定位，不自动播放。折叠、切页、打开历史或离开工作区都会暂停对应媒体；字幕弹窗仍保持原目标和实例，只传递实际可见状态。

底部使用同一按钮依次显示保存、确认、生成三步，直接调用原有函数和校验，不自动代替用户确认，也不重建按钮焦点。未找到及待进一步核对目标仍不能勾选。原句 ID 的边界输入归入可展开的调整区域，完整判断说明、保留区间、引用及排除依据继续可查。

异步保护增加两条约束：发起修改时使旧读取失效，并在提交中暂停启动新的轮询读取，防止提交成功后较早捕获的导出列表覆盖新批次；创建、继续和导出的成功回执捕获独立导航版本，只有用户未另行操作流程导航时才自动展示下一页。此版本不复用请求选择版本，不影响原幂等回执、模型预算或业务修订身份。

真实页面在 1280×720 中，剪辑卡片为 583px 高，候选与底部操作同时可见；320×800 中候选从约 y=381 开始，操作栏约 y=695～783，无整页横向溢出；640×360 中主按钮底部约 y=335，可直接操作。这些是指定窗口的布局观察，不代表用户效率提升。

真实交互已验证：新要求、标题及不完整边界输入跨三个视图保留；隐藏草稿拦截跨分析任务及历史请求切换，提示在遮罩关闭后可读。所有临时输入均已还原，未保存修订。历史请求对话框的焦点循环和 Esc 回焦通过；原视频定位至 255.489 秒后实际播放，切页及折叠后暂停。既有 32.333 秒成片实际播放，离开交付页后暂停；字幕校对弹窗及原 MP4 下载入口可打开。无请求的课程任务正确显示首次输入页。前端 171 项测试、类型检查和生产构建通过。
