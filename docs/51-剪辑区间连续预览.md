# 剪辑区间连续预览

2026-11-07：按需求剪辑支持在确认、生成之前，按候选的保留区间回看原视频。“预览全部区间”依次播放各段，跳过间隔，末段结束后暂停；“预览本段”用于单独检查边界。此功能只操作浏览器播放器，不保存方案、不确认或创建导出，不提交 ASR 或模型请求。

## 范围与权限

`intentPreviewParts` 检查来源原句 ID、整数毫秒边界、源时长、顺序和排除原句。完整目标最多十二段，不排序、合并或修改原方案；单段回看只检查指定段，另一段正在编辑时仍可核对合法部分。输出为独立的毫秒对象。

FOUND 和 NEEDS_REVIEW 的合法区间都能回看，但不会补语义证据、更改 status 或 enabled。原 `intentOutputValidation`、确认与导出条件保持不变。NOT_FOUND、无区间或无有效来源的目标不能开始预览。

## 播放与取消

`SequencePreview` 冻结输入，只在用户明确开始时调用一次 `play()`；跨段直接 seek，不创建迟到的自动播放请求。媒体事件和有界定时器观察实际 `currentTime`，卡顿时不按墙钟推进。进度累计保留时长，不包含跳过的间隔；倍速只改变观察定时，不改变原片时间范围。

每次播放使用独立 owner。取消清理定时观察和未完成启动，旧 play 结果、旧定时器或旧媒体事件不能干扰同一元素上的新预览。手动暂停或 seek 退出连续播放；末段停止并定位到结束时间。

组件先展开视频并等待元数据，再复核请求、选择及导航版本、源 URL、播放器实例和区间签名。准备最多等待十五秒；取消后迟到元数据不能启动旧意图。区间签名使用稳定内容，既能在已经 dirty 后再次修改时取消，也不会被五秒轮询产生的等值对象打断。

定位原句、修改区间、放弃草稿、切请求或工作区、打开历史、折叠视频和卸载均清理播放意图。小容器开始预览时展开播放器并定位，停止按钮保持可触达。浏览器回看受媒体事件和调度精度影响；正式拼接仍以原确认版本和 FFmpeg 导出的 MP4 为准，不提供帧精确预览承诺。

原生 `document.hidden` 变化也会取消连续预览或元数据准备，入口和准备完成后均检查可见性，返回前台不自动恢复。此保护只处理本功能的播放意图，不暂停普通自由回看，也不影响后台分析和导出任务。
