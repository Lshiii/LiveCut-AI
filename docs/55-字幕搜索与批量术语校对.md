# 字幕搜索与批量术语校对

2026-11-07。针对 ASR 对同一术语反复识别错误、逐页修改耗时的问题，在已有字幕校对内增加本地搜索、批量替换预览和会话内撤销。这是编辑效率能力，没有新增 ASR 或文本模型调用，也没有测得真实用户效率提升或付费转化。

## 使用流程

1. 在成片的“校对字幕”内搜索当前字幕文字。搜索覆盖所有分页，可选忽略大小写，与“只看待核对”共同筛选。
2. 展开“批量替换”，选择“全部字幕”或“当前筛选结果”。范围显示字幕条数，包含该范围的所有分页。
3. 填写替换内容后点击“预览替换”。每页展示最多 5 条完整替换前后文字，显示总条数、出现次数和成片时间；可返回列表定位对应字幕。
4. 明确点击“应用到本页字幕”才进入当前草稿，随后回到字幕列表。仍需原来的保存、人工核对和确认步骤。
5. “撤销最近替换”只恢复该批次的文字。受影响字幕后来被改字或删除时，整批拒绝撤销，保留后续编辑；无关字幕的手改、时间输入及核对标记会保留。

替换模式使用整个字幕编辑区，预览内容滚动，应用栏在滚动内容外部；完成后回到列表，避免在有限高度内堆叠两个编辑区域。

## 匹配与范围

- 使用字面量、非重叠匹配；不解释用户的正则表达式、HTML、反斜杠或 `$&`、`$1` 等替换语法。大小写选项采用 JavaScript Unicode 正则的大小写规则，不做同义词或模糊归一化。
- 查找内容须有非空白字符，最多 200 个 UTF-16 单元；替换内容最多 2000 个，可留空删除匹配部分。任何实际改变后的字幕为空、只含空白或超过原字幕上限时，整批拒绝应用。
- 保留原有 10000 条字幕、单条 2000 个 UTF-16 单元和总文字 2 MiB 限制。无变化时不创建批次；不触及字幕 ID、原始转写、时间、来源或逐句核对标记。
- 当前筛选结果与页面分页分离。切换筛选后旧预览失效，不隐式应用到新的范围。

## 草稿与来源保护

预览冻结成片身份、来源、base revision、内容 hash、本页采用快照的 epoch，以及完整 editable cues、原始时间输入、删除栈和保存结果待核对状态。替换条件、范围、草稿或来源变化后需要重新预览；离开校对视图也会使预览失效。应用前组件重新计算预览，父编辑器再次校验来源和完整草稿，纯函数再次核对实际 patch。

应用和撤销均将全局确认勾选重置为 false，暂停本页预览，不自动解除截断句的逐条核对要求。未知保存结果仍沿用原先只读核对流程，不因本地替换获得重提或导出权限。

仅保留最近一次替换的会话内撤销记录。保存、采用服务端快照、放弃修改、恢复草稿或关闭页面后记录清除。已有 schema v1 本机备份保存的是替换后的 editable 字幕；恢复前照常 fresh GET 核对来源与版本，不恢复 undo、pending 或确认权限。

## 验证边界

- 纯函数测试覆盖跨页、大小写、字面符号、多行与 emoji、空结果/长度/字节限制、篡改或过时预览、原子撤销和保留后续无关修改。
- 新增 21 项边界测试，前端共 296 项通过；类型检查和生产构建通过。
- 隔离浏览器使用真实 CaptionPanel 和 120 条明确标记的合成字幕：验证最后一条检索、4 条/8 处筛选范围与 6 条/12 处全文范围、预览第二页、应用后保留原始转写/无效时间输入/核对标记、撤销冲突、明确保存后清除 undo、fresh-page 本机恢复以及 320px 和低高度布局。
- 合成接口无代理，只在本 run 内存接受字幕 PUT；确认、导出与模型调用不被放行。它验证编辑交互，不代表真实 ASR 准确率或实际导出质量的新结论。
- 本地记录与截图位于忽略目录 `data/runs/caption-text-tools/`；合成草稿从浏览器清理前已归档。原有真实资源另做摘要对照。
