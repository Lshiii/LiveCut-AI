# 全文原句搜索与回看

用户记得视频里出现过的词时，应能直接定位原句，不必先创建剪辑方案或请求AI。已有原句选择器只服务于剪辑区间编辑，话题页只列出当前话题覆盖的原句。本功能新增独立的只读原句工作区，复用已完成话题任务的真实ASR和时间轴，不初始化审核、不改转写或草稿、不请求模型。

## 用户流程

解析完成后打开“原句搜索”。可分页浏览原始转写，输入文字或显示时间；空格分隔的词同时匹配同一句，按原视频顺序排列。这是字面搜索，不声称同义词或语义检索。显示命中数量、总原句数、页范围及无结果状态；每页最多20条请求，实际条数还受响应字符预算限制。

选择命中句后，独立读取前一句、命中句、后一句，显示全局时间。用户明确点击回看才定位播放器，不自动播放；可明确连续预览这三句覆盖的区间。手动拖动、切换选句、搜索/来源改变、隐藏或卸载后取消旧预览，迟到加载或play承诺不得复活。复制引用包含原视频名、全局起止时间和原句文字；仅复制当前明确选中的句子，不把未经人工校对的ASR说成准确引文。复制失败可重试，切源后迟到回执不能显示新来源已复制。

原视频与原句为主要内容，桌面并列、窄屏上下布局，正文和操作可滚动到达。保留其他工作区的草稿、未决提交和业务动作，不在搜索或翻页时挂载字幕编辑、触发业务保存、创建Agent会话或剪辑任务。

## 只读接口和共同契约

- GET `/api/jobs/{jobId}/transcript`：q默认空、最多200个UTF-16单元；offset默认0且为非负安全整数（不超过9007199254740991），limit默认20且为1～50；offset超出匹配总数返回空页、next_offset=null，不截断或回绕。可带64位小写hex的source_fingerprint固定此前来源；不匹配返回409 TRANSCRIPT_SOURCE_CHANGED。重复或未知参数返回400 INVALID_TRANSCRIPT_QUERY。
- GET `/api/jobs/{jobId}/transcript/context`：必须提供utterance_id和source_fingerprint，前后各最多一句；无此原句404 TRANSCRIPT_UTTERANCE_NOT_FOUND。
- 仅支持已完成REVIEW_READY且analysis_mode=topics的任务。不存在404 JOB_NOT_FOUND，未就绪/非话题409 TRANSCRIPT_NOT_READY，产物缺失、篡改或来源不符409 TRANSCRIPT_SOURCE_INVALID；参数校验先于读取大产物。旧接口和Worker协议不变。
- 两种响应共同source对象：job_id、video_id、generation、source_video_sha256、transcript_sha256、analysis_sha256、duration_ms、source_fingerprint。fingerprint为版本化固定格式的这些标量的SHA256，不含私有key或token，不能用摘要替代真实来源核验。
- 页响应：schema_version=`1.0`、data_kind=`transcript_page`、source、q（保留HTTP请求原文，仅匹配时归一化）、offset、limit、total_utterances、matched_utterances、next_offset（整数或null）、items。items为utterance_id/start_ms/end_ms/text；不返回全文或每条附带上下文。
- 上下文响应：schema_version=`1.0`、data_kind=`transcript_context`、source、center、previous（对象或null）、next（对象或null）。
- 原句保留原文，规范化仅用于匹配：NFKC、Locale.ROOT小写、Unicode White_Space及FEFF分词、最多8个AND词。匹配文本与显示时间`MM:SS`/`HH:MM:SS`，无正则、无SQL通配符语义。最多100000句，沿用原ASR每句100000个UTF-16单元、合法唯一ID、不重叠有序时间边界。页内text累计最多200000个UTF-16单元；至少容纳一条，next_offset按实收条数推进，不能跳过长原句或伪造空页。不把字符预算说成精确UTF-8响应字节上限。

Java独立读取任务、视频和成功ASR/TIMELINE身份；仅SELECT，无FOR UPDATE或审核初始化。文件IO在业务事务和行锁之外；通过既有ArtifactVerifier核对manifest、文件、冻结identity及ASR与时间轴utterances一致，返回前重新读取并比较全部来源身份。其他同视频Agent/导出进度带来的state_version、updated_at、调用计数或心跳变化不属于ASR来源身份，不能使同一转写误报已变。合法已有复用ASR仍按现有stage identity核验。不得绕过原产物校验或从可编辑标题/字幕合成原句，不增加数据库迁移或检索服务。

当前ArtifactVerifier仍会整体读取有界JSON（既有8MiB上限）。本功能的分页减少HTTP响应与页面渲染，不声称服务端避免加载全文、构建了全文索引或有未经测量的性能提升。

共同结构见[分页Schema](../contracts/transcript-page.schema.json)与[上下文Schema](../contracts/transcript-context.schema.json)。fingerprint按UTF-8固定字符串计算SHA256：`transcript-source-v1\n{job_id}\n{video_id}\n{generation十进制}\n{source_video_sha256}\n{transcript_sha256}\n{analysis_sha256}\n{duration_ms十进制}\n`，含末尾换行。字段必须先核合法值；这个标识固定公开来源，不替代文件核验。JSON Schema长度按Unicode码点，而Java/浏览器另严格核UTF-16预算，两者不混称。

## 前端协议

仅当前工作区可见时发起读取。搜索显式提交，分页固定已提交q与同一来源；未提交搜索文字不被翻页覆盖。返回时保留搜索词、已读结果和选句，按需核对；失败保留旧结果并明确旧范围，不把旧结果标成新查询。加载、错误、无结果分别呈现；失败可以显式重试。独立读取token与AbortController隔离页/上下文，旧finally不能清新请求，切源旧结果不可操作。

严格验证响应来源、边界、顺序、数量和next_offset；不靠类型断言信任网络JSON。匹配高亮只能使用文字节点，不使用v-html。复制不自动下载或创建笔记；播放、选句和草稿均不作为剪辑确认凭据。
