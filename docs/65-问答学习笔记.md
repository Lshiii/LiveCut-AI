# 问答学习笔记

目标：已看懂的视频回答可以保存为自己的资料。每个成功的VIDEO会话轮次提供“学习笔记”，明确保留视频依据、通用知识或证据不足标记，带走原问题、原回答、原句与精确时间、实际引用的截图。直接整理已有成功结果，不再生成摘要，不请求模型，不包含原视频或完整转写，不自动剪辑。

## 使用流程

成功回答下点击“学习笔记”→只读核对本轮来源与可导出内容→复制文字笔记，或下载含图ZIP。复制仅含文字与截图来源信息，图片通过ZIP交付；不能把本机API图片链接当作离线图片。未完成/失败/取消的轮次不导出。新草稿、原提交回执、播放位置与选择原句保持独立。

## 接口

- `GET /api/agent-turns/{id}/note`：JSON，严格字段为 `schema_version:1, turn_id, session_id, job_id, video_id, source_hash, transcript_hash, result_hash, source_filename, answer_scope, citation_count, image_count, markdown, download_filename`。四个ID及来源与本轮一致，hash为64位小写十六进制；`download_filename`固定为 `video-note-{turn_id}.zip`。markdown为可复制的文字笔记，截图只列实际时间、说明与文件名，明确图片在ZIP中。
- `GET /api/agent-turns/{id}/note/download`：同源、同轮次ZIP。文件为 `note.md`、`source.json`、`images/f0001.jpg`等，截图仅包含被visual_citations实际引用的帧，编号可不连续。`note.md`在文字笔记后附本地相对路径图片，离线可读；两种文字中的问题、回答和原句必须一致。响应包含 `X-LiveCut-Note-Turn-Id` 和 `X-LiveCut-Note-Result-Hash`，前端与当前已核对笔记匹配后才触发保存。
- `source.json`只包含导出所需公开来源、模型/提示版本、回答分类、引用原句和实际引用的帧元数据；不含凭证、内部存储键、run_token、调用账本、原始供应商响应或未引用转写。

不增加DB迁移或Worker阶段。服务端读取时先按原analysis→session→turn锁顺序冻结成功快照，验证当前来源、result_hash、回答契约、结果manifest和agent_answer产物一致；视觉轮次沿现有JPEG/PTS/manifest核验后仅输出被引用图片。不能只因数据库有result_json就允许导出；失败不降级为旧缓存、缺图包或合成内容。打包在已冻结快照的事务外完成。

## 文档内容

包含视频文件名、问题、回答分类、原回答、原句全文及全局毫秒时间、视觉说明及实际PTS/time base/JPEG hash、可选用户位置提示、模型/提示版本和source hash。用户附加位置单列查找提示，不当作已看画面；画面不是原句剪辑锚点。GENERAL明确不是视频原话，INSUFFICIENT保留证据不足，纯视觉回答不添加伪造原句。

没有可用session/turn/time深链时只记录时间和来源，不构造不能定位的“回看”URL。原文中的HTML、远程图片和链接按文字处理，不通过模型内容或视频文件名生成远程请求或ZIP路径；仅程序生成的本地图片路径可成为嵌入。保留便于阅读的段落、列表和强调，不能通过转义无声删改原答案。

## 资源与边界

单轮最多24条原句、32个引用帧；沿视觉已有1MiB/帧、16MiB总图上限。单份文字/来源JSON各不超过2MiB UTF-8，ZIP最多24MiB，超限明确 `AGENT_NOTE_TOO_LARGE`，不截断。服务端最多并行准备2份，忙时429 `AGENT_NOTE_BUSY`，permit覆盖来源核验和打包且finally释放。ZIP条目固定命名、无目录穿越；文本UTF-8，条目时间固定，不把生成时钟或本机路径写入文件。

前端只在用户明确展开/复制/下载时读取，不随轮询预生成所有笔记。JSON HTTP正文最多5MiB（包括转义开销），另核markdown的2MiB UTF-8上限；所有读取有大小/类型/超时限制，切任务/会话/轮次或组件失活后迟到结果不能覆盖当前状态或触发下载；原任务模型预算不变。剪贴板失败保留已核对内容，用户仍可下载。错误使用固定中文，不显示任意供应商或服务端原文。

## 验收

覆盖文本1.0、视觉1.1、附加位置1.2、GENERAL/INSUFFICIENT、0时刻、无原句的视觉回答、多帧去重且只导出引用图片；篡改结果/来源/manifest/JPEG、未成功、非VIDEO、超限与资源permit回收均明确拒绝。解包真实已完成轮次，核note内容、source公开字段和每张图字节hash；导出前后数据库快照与模型账本不变。浏览器实际下载ZIP、复制成功/失败、迟到读取、320px与桌面布局均检查。工程验收不代表笔记能提高学习效率或用户愿意付费，这些需用户使用反馈验证。
