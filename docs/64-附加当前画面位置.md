# 给视频问题附加当前画面位置

2026-11-09：按需看图首版需要用户在问题中手写时间，无法可靠解释“这张图”“这一层”的指向。本功能让用户显式把当前播放位置附到视觉问题中；位置是查找提示，不是已经观察的截图或视频事实。

## 使用流程

在“结合画面”模式，展开原视频并停在想讨论的位置，点击“附加当前画面位置”。程序取消区间播放意图并暂停播放器，检查当前源、已加载画面、非seeking和时间范围后，向下取整 currentTime 到整数毫秒。提问区显示冻结的定位提示，可移除或重新附加。随后播放或拖动进度条不会改变提示。

带位置的请求先在本地执行一次真实取帧，首次模型请求直接携带该图；不先付费让模型再次选择这个已明确的位置。首个工具由用户附加位置触发，后续工具仍由模型选择。画面无法取得时在模型调用前明确失败，不用ASR猜成已经看过画面。

切回文本模式保留提示，并要求明确移除或切回画面模式后才提交，避免静默改变用户意图。未决原提交的位置和当前草稿的位置独立保留。用户没有附加位置时，原文本/视觉提问保持原协议。

## 跨端契约

- 新增可选 POST turns 字段 `focus_timestamp_ms`，仅 `visual_mode:"frames"` 可用。必须是安全整数，`0 <= value < session.source.duration_ms`；0有效，显式null、布尔、浮点、负数和EOF均拒绝。不得从自然语言问题猜出并自动填写该字段。
- V21 给 agent_turn 增加 nullable BIGINT focus_timestamp_ms；旧行NULL。公开Turn和私有claim仅在非NULL时输出该字段，不为旧记录补null。
- 旧无位置指纹完全不变。有位置时仅在旧turnFingerprint后追加 `\nfocus_timestamp_ms=` 和十进制整数。原key优先核对既有记录，不因服务模型配置变化或会话繁忙而丢弃旧结果。same key不同位置冲突。
- 使用专用 `AGENT_VISUAL_FOCUS` 阶段，owner仍AGENT_TURN，保守占TEXT+FFMPEG两资源。旧视觉Worker不能领取新阶段，也不能忽略位置后先付费。未配置视觉服务的默认Worker继续只广告旧7种能力。
- 保留 `/api/agent-capabilities` 五字段形状，新增只读 `GET /api/agent-capabilities/focus`，精确返回 `{focus_timestamp_supported:true}`。新前端遇到该路由不支持/不可核验时，关闭附加位置入口并保留现有草稿；普通视觉提问仍按原能力检查。
- 有位置结果使用独立 `agent-answer-visual-focus.schema.json` 1.2，prompt_version=`video-agent-visual-focus-v1`。无位置仍为旧1.1，旧1.0不变。
- 1.2保留1.1字段，并强制顶层 `focus_timestamp_ms` 与冻结输入完全相同。所有tool_calls增加程序控制的 `origin:"USER_FOCUS"|"MODEL"`：首步固定USER_FOCUS、inspect_frames({timestamps_ms:[focus]})；后续均MODEL。首步须实际产生已入模帧，不能仅有一个位置就假装观察成功。

结果里的位置、工具origin由程序组装，不由模型选择或生成。1.2的帧/原句引用仍须满足1.1全部真实来源、精确PTS、hash、范围和工具并集约束；位置本身不进入visual_evidence、不成为citation或剪辑锚点。

## 预算与恢复

首个本地取帧占1/4工具步骤、1/32不同帧，后续最多3步；不新增隐藏的模型请求。请求上限仅1次时也允许带真实首帧直接回答。来源、MEDIA、缓存、发布失败的前置拒绝与同轮TEXT账本、UNKNOWN、物理重试和纯文本fallback禁用均保留。

位置进入stage input hash、Worker配置指纹、SYSTEM/实际messages与预算计划。旧省略路径不改SYSTEM、payload、prompt_version或checkpoint指纹。初始化观察须先持久化，恢复不能重新抽不同的图或重新读取浏览器当前位置；缓存损坏拒绝，不重标旧图片。

新请求在额度为0或无法核实时不派发模型。已成功付费但尚未发布的同一请求，额度为0仍可沿已冻结计划和已验证账本重放原响应，不能因先查余额而挡住成功恢复。

前端immutable entry保留原key/body中的位置。恢复回执须核对原模式、原位置；只有精确业务不存在才原样重试。原请求成功后清草稿也要核对位置：如果用户后来附加了不同位置，即使问题、模式和预算相同也不能清掉新草稿。SESSION恢复仍不自动补发问题。

## 验收边界

工程回归使用受控模型验证链路。覆盖0时刻、非法类型/EOF、旧省略兼容、首次请求真实JPEG、1次预算、0预算、预算用尽后的重放、UNKNOWN、首次观察持久化失败、旧Worker隔离、原位置回执恢复、播放器移动后chip不变、切源/隐藏/迟到seek与320px布局。

播放器时间只是用户选的位置，服务器抽到的帧有独立实际PTS，二者可以略有不同；不宣称截图像素必定等于浏览器暂停画面。

### 2026-11-09 独立真实小样

用户授权的首轮上限为4次模型请求、32个不同帧，无新增ASR。复用已有视频、转写与分析，在独立数据库和存储中执行；真实供应商失败保留，不用合成响应替代。
